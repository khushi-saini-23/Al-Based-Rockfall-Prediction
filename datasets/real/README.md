# Future measured datasets

Place independently sourced, documented mine data in the category directories
here. No real datasets are included yet. Record provenance, license, site and
sensor identifiers, units, time zone, sampling interval, missingness, and how
each rockfall event and non-event observation period was verified before any
scientific training or evaluation.

The CSV path, column and verified-coverage contract for the research training
pipeline is in [docs/ML_PIPELINE.md](../../docs/ML_PIPELINE.md). An empty folder
or a positive-only event list is insufficient for model training.
